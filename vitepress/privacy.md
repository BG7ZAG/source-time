# 源时隐私政策

**版本：2.3**
**生效日期：2026 年 10 月 16 日**
**适用产品：源时（SourceTime）HarmonyOS 应用**
**运营者：黄国栋**

源时（SourceTime，以下简称“本应用”）是一款本地优先的鸿蒙（HarmonyOS）TOTP 动态口令工具。我们非常重视你的个人信息与隐私保护，本政策说明本应用如何处理你的信息，以及你可以如何行使相关权利。

## 一、引言与适用范围

1. 本应用基于 RFC 6238 在设备本地生成一次性验证码。
2. 本政策适用于应用内的全部数据处理行为，包括数据收集、本地加密存储、运行日志、WebDAV 同步、剪贴板使用与数据删除。
3. 本政策仅涵盖本应用自身。你自行配置的 WebDAV 服务器，以及操作系统提供的剪贴板、相机等系统能力，适用相应服务方或系统的规则。
4. 本应用为开源应用（MIT 协议），源代码可供审查，你可以通过审查代码验证本政策的各项声明。

## 二、我们如何处理信息

**本应用不收集、不上传你的个人信息，不要求注册或登录。**

仅在设备本地处理以下由你主动提供的信息：

| 信息 | 用途 | 是否离开设备 |
|------|------|-------------|
| 发行方、账号、TOTP 密钥 | 在本地生成动态口令 | 否 |
| 加密密钥 | 加密保存口令配置（AES-256-GCM） | 否（托管于系统安全存储） |
| 应用锁 PIN 的派生校验值 | 校验应用锁，不保存 PIN 明文 | 否 |
| WebDAV 服务器地址、用户名、密码 | 在你启用同步时访问你指定的服务器 | 仅发送至你指定的服务器 |
| 运行日志 | 故障排查，写入前已脱敏 | 否 |

我们不会进行用户画像、精准营销或行为分析。

## 三、权限调用

| 权限 | 用途 | 触发时机 |
|------|------|---------|
| 相机 | 扫描 otpauth 二维码录入密钥 | 你点击“扫描二维码”时 |
| 网络 | 访问你配置的 WebDAV 服务器 | 你启用并执行同步时 |
| 分布式数据同步 | 将 WebDAV 配置同步到同账号手表 | 你主动点击“同步到手表”时 |
| 隐私窗口 | 窗口防截屏、防录屏 | 应用运行期间 |
| 剪贴板 | 你点击“复制”时写入口令 | 你主动复制时 |

拒绝上述权限不影响本应用的本地口令生成功能。

## 四、数据存储与安全

1. 你的 TOTP 数据经 AES-256-GCM 加密后存储；加密密钥通过 PBKDF2-HMAC-SHA256（10 万次迭代）派生，并托管于系统安全存储。
2. 本应用不参与系统备份（`allowToBackupRestore=false`），数据不会随系统备份离开设备。
3. 应用锁仅保存 PIN 的派生校验值，不保存 PIN 明文。
4. 运行日志仅保存在应用沙箱内，不上传；写盘与展示前会按脱敏规则避免记录密钥、密码等敏感信息。

## 五、数据共享与传输

1. 我们不会主动向开发者或任何第三方上传、共享、转让你的数据。
2. 启用 WebDAV 后，仅**加密文件**会上传到你自己指定的服务器，服务端只能看到密文。
3. 默认只允许 https 地址；你可以显式开启“允许不安全连接”改用 http，此时凭据与密文在传输中不受 TLS 保护，风险由你自行承担。
4. 开发者不运营任何接收你数据的服务器。

## 六、你的权利

| 权利 | 操作方式 |
|------|---------|
| 访问 | 首页查看口令卡片；设置 → 安全与密钥、WebDAV 同步查看配置 |
| 更正 | 长按口令卡片 → 重命名；设置 → WebDAV 同步修改服务器配置 |
| 删除 | 左滑口令卡片 → 删除；或卸载应用 / 清除应用数据 |
| 撤回同意 | 关闭 WebDAV 同步、关闭应用锁；或卸载应用 |
| 注销 | 本应用无账号体系，无需注销 |

## 七、未成年人保护

本应用不面向未成年人单独提供服务，不主动收集年龄、身份等信息。未成年人应在监护人指导下使用。

## 八、本政策的更新

本政策可能随功能或法规变化而更新，更新后会在本页面发布并标注新的版本与生效日期。重大变更会在应用内提示。
