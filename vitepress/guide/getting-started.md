# 快速开始

## 运行环境

- 平台：HarmonyOS NEXT
- 开发语言：ArkTS / ArkUI
- 构建工具：DevEco Studio + hvigor

## 获取与安装

目前支持鸿蒙原生安装：自行构建 `entry-default-signed.hap` 后侧载，后续上架华为应用市场。

本仓库当前未提供 Release 安装包；正式版、测试版与更新日志将在应用市场上架后统一发布。

## 首次启动流程

```text
启动应用
   ↓
隐私政策弹窗（不同意 → 退出；同意并继续）
   ↓
加密密钥初始化（保护你的数据：输入 / 生成 / 复制密钥）
   ↓
首页（验证码列表）
```

隐私政策确认与加密密钥初始化是首次使用流程的一部分，**不得绕过**；隐私政策版本重大升级时会重新要求确认。

## 加密密钥初始化

首次启动会进入「保护你的数据」流程，你可以：

- **手动输入**：使用自己记得住的字符串作为加密密钥
- **随机生成**：一键生成 256-bit 系统安全随机密钥
- **一键复制**：生成后立即复制密钥并妥善保存

> 源时不会保存明文加密密钥，也不提供服务器端找回功能。若忘记或丢失密钥，已加密数据可能无法恢复，请务必妥善备份。

::: tip 温馨提示
密钥是解密本地数据与云端备份的唯一凭据，建议生成后立刻保存到密码管理器或离线记录中。
:::

## 添加验证码

进入首页后，可通过两种方式添加 TOTP：

- **扫码录入**：解析 `otpauth://totp/...` 二维码，确认后保存
- **手动录入**：填写发行方、账号、密钥、算法、位数、周期

## 本地构建文档站

本目录本身就是一个 VitePress 文档站，本地预览命令：

```bash
# 进入文档站目录
cd vitepress

# 安装依赖
npm install

# 本地预览（默认 http://localhost:5173）
npm run dev

# 构建静态站点，产物在 .vitepress/dist
npm run build

# 预览构建产物
npm run preview
```
