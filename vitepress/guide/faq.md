# 常见问题

## 源时会上传我的密钥到云端吗？

不会。源时不上传任何第三方云端、不建用户账号体系。WebDAV 同步前会先在本地加密，服务端只保存 AES-256-GCM 密文文件，无法解密。

## 忘记加密密钥怎么办？

源时不会保存明文加密密钥，也不提供服务器端找回功能。**如果忘记或丢失密钥，已加密数据可能无法恢复。** 请务必在生成密钥后立即妥善备份。

## 断网还能用吗？

可以。源时是离线优先设计，查看、新增、删除验证码，修改密钥、复制验证码全部无需联网。WebDAV 仅作为同步与备份能力。

## 支持哪些 TOTP 参数？

- 算法：SHA1 / SHA256 / SHA512
- 位数：6 位 / 8 位
- 周期：默认 30 秒
- 协议：RFC 6238，兼容全网 2FA 服务

## 如何导入已有验证码？

- **扫码**：扫描对方的 `otpauth://totp/...` 二维码，确认后保存。
- **手动**：填写发行方、账号、密钥、算法、位数、周期。

## 云端备份会覆盖以前的数据吗？

不会。每次推送都会生成一份带时间戳的快照文件（如 `sourcetime-20261014-154512.enc`），**不覆盖历史**。

## 同步冲突怎么处理？

V1 采用 **Last Write Wins**（最后写入为准）策略；Push / Pull 通过同步队列串行执行，避免并发竞争。

## WebDAV 可以用 http 吗？

默认强制 `https`。确有必要时，可在设置中显式开启明文 `http`。

## 支持哪些设备？

适配手机、平板、折叠屏设备，基于 HarmonyOS NEXT 原生开发（ArkTS / ArkUI）。

## 如何本地预览文档站？

```bash
cd vitepress
npm install
npm run dev
```

构建产物位于 `vitepress/.vitepress/dist`。

## V1 有哪些功能尚未提供？

HOTP、密码管理、用户账号体系、自建云服务、分类标签、多文件同步、多版本历史、自动合并冲突、浏览器插件。
